# Runbook — AAP MCP + Microsoft Copilot Studio

Primary path: register your existing AAP MCP server with **Copilot Studio**. Azure AI Foundry is optional — see [LEGACY-FOUNDRY.md](LEGACY-FOUNDRY.md).

---

## 1. What you are running

| Step | Playbook / tag | What it does |
|------|----------------|--------------|
| MCP verify | `site.yml --tags verify_mcp` | POST `initialize` to `/mcp` and each toolset |
| OpenAPI | `copilot_openapi` | Render `aap-mcp-openapi.yaml` (streamable MCP) |
| Wizard guide | `copilot_wizard` | `copilot-setup-artifacts/MCP-SETUP-WIZARD.md` |
| Connector artifacts | `copilot_artifacts` | `SETUP-INSTRUCTIONS.txt`, OpenAPI copy |
| Connector API | `copilot_connector` | Power Platform custom connector (needs `az login`) |

**This repo does not deploy MCP on AAP.** Set `aap_mcp_base_url` to your existing route.

---

## 2. Prerequisites

| Tool | Purpose |
|------|---------|
| **Ansible** | Run playbooks |
| **Azure CLI** | Only for `copilot_connector` mode (`az login`) |
| **Copilot Studio** | Agent with generative orchestration enabled |

### AAP MCP

| Item | Variable |
|------|----------|
| MCP URL | `aap_mcp_base_url` |
| Credentials | `aap_user`, `aap_password` (Basic auth) |

### Copilot Studio

- Valid public SSL on MCP host
- **Streamable HTTP** MCP transport ([Microsoft docs](https://learn.microsoft.com/en-us/microsoft-copilot-studio/mcp-add-existing-server-to-agent))
- Trust folder / complete wizard auth when prompted in UI

## 3. Configure variables

```bash
cp group_vars/all.yml.example group_vars/all.yml
```

```yaml
aap_mcp_base_url: https://your-aap-mcp.example.com
aap_user: admin
aap_password: "<secret>"

copilot_setup_mode: both    # wizard | connector | both
copilot_agent_name: aap-automation-copilot
```

---

## 4. Run

```bash
# Interactive (recommended first time)
./scripts/setup-copilot.sh

# Full flow
ansible-playbook playbooks/site.yml

# Wizard instructions only
ansible-playbook playbooks/site.yml -e copilot_setup_mode=wizard --tags copilot_wizard

# MCP verify only
ansible-playbook playbooks/site.yml --tags verify_mcp
```

---

## 5. Copilot Studio UI (after playbook)

### Option A — MCP wizard (recommended)

1. Open [copilot-setup-artifacts/MCP-SETUP-WIZARD.md](../copilot-setup-artifacts/MCP-SETUP-WIZARD.md) (generated by playbook).
2. Copilot Studio → your agent → **Tools** → **Add tool** → **MCP**.
3. Enter MCP URL and `Authorization: Basic …` from the guide.

### Option B — Custom connector

1. Follow `copilot-setup-artifacts/SETUP-INSTRUCTIONS.txt`.
2. Import `aap-mcp-openapi.yaml` in [Power Apps](https://make.powerapps.com).
3. Copilot Studio → **Tools** → **Custom connector**.

## 6. Verify MCP manually

```bash
AUTH=$(echo -n "admin:PASSWORD" | base64)
curl -sk -X POST "${AAP_MCP_URL}/mcp" \
  -H "Authorization: Basic ${AUTH}" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"test","version":"1.0"}}}'
```

## 8. Troubleshooting

| Issue | Check |
|-------|--------|
| MCP verify fails | URL, Basic auth, `aap_validate_certs` |
| Connector 401 | `Authorization` must be `Basic <token>` with space |
| Copilot tools missing | Generative orchestration enabled |
| SSL errors in Power Platform | Public CA cert on MCP host |
| Playbook skips connector | `copilot_setup_mode` must include `connector` |
