# Legacy Foundry scripts

These scripts supported **Azure AI Foundry** registration before Copilot Studio became the primary path.

Use [`playbooks/foundry-site.yml`](../../playbooks/foundry-site.yml) and [docs/LEGACY-FOUNDRY.md](../../docs/LEGACY-FOUNDRY.md) instead.

| Script | Purpose |
|--------|---------|
| `configure-foundry-rest.sh` | REST helper for Foundry project connection |
| `configure-foundry-agent.py` | Foundry agent + MCP tool configuration |
| `discover-foundry-endpoint.sh` | Discover Foundry project endpoint via Azure CLI |
